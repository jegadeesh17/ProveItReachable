    Key to the three flags

    likely reachable
    A call path from the repository’s own code to the vulnerable function was found, with file and line.
    uncertain
    The evidence was missing or a step failed. It is a printed result, never a pass.
    no reachable path detected
    No path was found within the scope stated for that finding. It is not proof of safety.
